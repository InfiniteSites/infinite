# Infinite Unlocker

A semi‑untethered Safari re‑jailbreak tool for iOS 12 – 12.5.8.

Based on TotallyNotSpyware v2

---

## What’s Different? 🚀

### iOS 12.5.8 Support 📱
Officially supports iOS 12 – 12.5.8.

Tested on an iPhone 5S running iOS 12.5.8, where it worked perfectly.

---

### Modern UI 🎨
Infinite Unlocker features a clean, modern interface designed to feel much newer than typical jailbreak pages while still remaining fully compatible with older Safari engines on iOS 12.

The layout is simple, responsive, and optimized for mobile so the jailbreak process feels smoother and easier to use on older devices.

---

### Fully Offline Re‑Jailbreak 🌐
Once set up, Infinite Unlocker can re‑jailbreak completely offline.

The website is designed to work smoothly with older Safari engines on iOS 12, meaning the entire process can run locally without needing internet access every time.

After the initial setup, there is no need to rely on Chimera repeatedly.

---

## First‑Time Setup Requirement 🔓

Infinite Unlocker is a re‑jailbreak tool, not a first‑time jailbreak.

You must:

1. Jailbreak once using Chimera
2. Run Infinite Unlocker once while connected to Wi‑Fi

After that, you can re‑jailbreak anytime without internet.

(A11 devices are currently not supported.)
